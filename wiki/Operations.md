## Why most of this is a gap

Everything on these pages needs access we do not yet hold — hosting consoles, the SQL Server, cPanel,
DNS, and the Mailgun, Mailchimp and Power BI accounts. See [Access Register](/Access-Register).

The code review told us a great deal about the applications. It can tell us almost nothing about the
infrastructure they run on. That part of the landscape is still entirely dependent on what one person
knows, which is precisely the dependency the handover is meant to remove. Getting these consoles open
is therefore the highest-value use of the period before 2026-09-21.
